# Troubleshooting

[Home](../README.md) · [Controls](controls.md) · [Crafting](crafting.md) · [Help](troubleshooting.md)

## Starting

| Problem | Fix |
|---|---|
| **Windows protected your PC** | Choose **More info → Run anyway**. The program isn't code-signed |
| Error mentioning a DLL (for example `MSVCP140.dll`) | Install **Microsoft Visual C++ Redistributable (x64)** from Microsoft, then start again |
| Slow start, or a pause at the first key press | Normal: the game prepares itself, up to a minute each time. Don't start a second copy |
| Window doesn't fit the screen | It shrinks automatically. If it's still cut off, report your screen resolution |

## Keys do not work

1. Click inside the game window.
2. While sleeping or resting, keys are ignored until it ends.
3. Arrow keys and the number pad aren't used; see [Controls](controls.md).
4. On non-English keyboard layouts, punctuation keys may be elsewhere. The console lists every key at startup.
5. Check the action's requirements: a nearby table, materials, bow and arrows, mana, a learned spell, or XP.

## Gameplay

| Problem | Check |
|---|---|
| Crafting does nothing | All materials present; table within the 8 surrounding tiles; furnace too for iron; you can't craft an equal or lower tier. [Crafting](crafting.md) |
| Mining does nothing | Your [pickaxe tier](crafting.md#mining-requirements) |
| Can't go down | Stand on the ladder and press **.**; below the Overworld, defeat 8 enemies on that floor first. [Floors](world.md#moving-between-floors) |
| Attacks do little damage | Enemy [resistances](combat.md#enemy-resistances): Fire and Ice Realm enemies resist physical damage heavily |

## Saving

| Console message or symptom | Meaning |
|---|---|
| Episode … **skipped** | Shorter than 100 steps; nothing to do |
| **disk writer is falling behind** | The game pauses briefly while saving catches up. If it happens often, report it |
| **RECORDING STOPPED** | A disk problem, for example a full disk. Keep the files and the console text, and contact the organizer |
| A `.tmp` file after a crash | Send it with your other files; don't rename it |
| Missing episode numbers | Skipped short episodes |

## Report a problem

Contact the organizer (see [Your assignment](study-details.md#contact)) with your participant ID, what you were doing, and a screenshot or copy of the console text.
