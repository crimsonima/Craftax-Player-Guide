# Controls

## Move and interact

| Key | Action |
|---|---|
| W / A / S / D | Move up / left / down / right, facing that way |
| Space | Act on the tile you face: collect, mine, drink, open a chest, attack |
| Q | Wait one step |
| Tab | Sleep (restores energy) |
| E | Rest (restores health) |
| . (period) | Go down a ladder you stand on |
| , (comma) | Go up a ladder you stand on |

## Craft (next to a crafting table)

| Key | Pickaxe | Key | Sword |
|---|---|---|---|
| 1 | Wood | 5 | Wood |
| 2 | Stone | 6 | Stone |
| 3 | Iron\* | 7 | Iron\* |
| 4 | Diamond | 8 | Diamond |

| Key | Makes |
|---|---|
| Y | One iron armour piece\* |
| U | One diamond armour piece |
| O | 2 arrows |
| [ | 4 torches |

\*Also needs a furnace nearby. Costs: [Crafting](crafting.md).

## Place (on the tile you face)

| Key | Places | Cost |
|---|---|---|
| T | Crafting table | 2 wood |
| F | Furnace | 1 stone |
| R | Stone block | 1 stone |
| P | Sapling, on grass | 1 sapling |
| J | Torch | 1 torch |

## Fight and magic

| Key | Action |
|---|---|
| I | Shoot an arrow (needs a bow and arrows) |
| G / H | Cast fireball / iceball (spell learned, 2 mana) |
| M | Read a book to learn a spell |

## Upgrade

| Key | Action |
|---|---|
| ] / - / = | Spend 1 XP on dexterity / strength / intelligence |
| K / ; / L | Enchant sword / bow / armour, facing an enchantment table (gem + 9 mana) |

## Potions

**Z X C V B N** drink a red, green, blue, pink, cyan or yellow potion. Colours are reshuffled every episode: see [Potions](survival.md#potions).

## Tips

- Arrow keys and the number pad aren't used.
- On non-English keyboard layouts, punctuation keys may be elsewhere; the console lists every key at startup.
- While sleeping or resting, keys are ignored until it ends.
